# 🍬 Nassau Candy Distributor Dashboard

🚀 **Live Dashboard:** https://ncd-dashboard-project.streamlit.app/

An interactive Product Line Profitability & Logistics Intelligence Dashboard for Nassau Candy Distributor, built to analyze sales, profit, shipping efficiency and factory performance.

### 📊 Overview
Nassau Candy ships from 5 regional factories across US & Canada. This dashboard transforms raw order & shipment data into business intelligence - identifying most profitable products, delayed routes, and regional performance.

### ✨ Dashboard Features
- **KPI Overview:** Total Sales, Total Profit, Order Volume, Avg Delivery Days
- **Product Profitability:** Most profitable SKUs, categories, margin analysis
- **Factory Performance:** Factory-wise sales, profit, and efficiency comparison
- **Monthly Sales & Profit Trend:** Time-series analysis (Fixed for pandas 2.x)
- **Shipping & Route Analysis:** Delay analysis, geographic bottlenecks
- **Customer Insights:** Top customers, regional distribution

### 🛠️ Tech Stack
- Python, Pandas, Plotly, Streamlit

### ▶️ Run Locally
pip install -r requirements.txt
streamlit run app.py
